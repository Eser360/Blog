Antigravity'nin download sayfasında SUSE için verilen komutun çalışması için biraz değişiklik yapılması gerekiyor.

Öncelikle terminali açın ve aşağıdaki kodu çalıştırın

### Depoyu /etc/zypp/repos.d dizinine eklemek için

BASH

```cpp
sudo tee /etc/zypp/repos.d/antigravity.repo << 'EOL'
[antigravity-rpm]
name=Antigravity RPM Repository
enabled=1
autorefresh=1
baseurl=https://us-central1-yum.pkg.dev/projects/antigravity-auto-updater-dev/antigravity-rpm
gpgcheck=0
EOL
```

### Daha sonra paket önbelleğini güncelliyoruz

BASH

```cpp
sudo zypper refresh
```

### Son olarak Antigravity'i yükleyin

BASH

```cpp
sudo zypper install antigravity
```
